# Security Model

## Security Score Components

The security score is not a mysterious composite. It exposes individual components:

- Repository provenance
- Maintainer identity
- Dependency health
- Secrets exposure
- Permission scope
- Network access
- Command execution
- Authentication
- Transport encryption
- Update cadence
- Documentation
- Security policy
- Known advisories

## Security Functions

- Repository scanning
- Dependency scanning
- Package risk analysis
- Secret detection
- Permission analysis
- Tool capability analysis
- Network-access detection
- File-system-access detection
- Command-execution detection
- Authentication review
- Transport security review
- Vulnerability tracking
- Advisory publication
- Maintainer verification
- Provenance tracking
- Signature verification where available

## Score Labels

All security scores are platform assessments, not guarantees.

## Advisory Tracking

Security advisories are tracked as entities with:
- Vulnerability ID
- Severity
- Affected versions
- Patched versions
- Published date
- Source
