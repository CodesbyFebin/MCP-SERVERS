# Editorial Workflow

## Overview

The editorial workflow ensures all published content meets quality standards.

## Review Process

1. **Candidate Generation** - System generates candidate pages from entities and relationships
2. **Intent Validation** - Validate search intent and information gain
3. **Evidence Review** - Verify all claims have supporting evidence
4. **Brief Approval** - Editor approves content brief
5. **Draft Generation** - System generates section drafts
6. **Automated Validation** - Run quality gates, duplicate checks, schema validation
7. **Editorial Review** - Human editor reviews exact content hash
8. **Approval** - Editor approves exact content hash
9. **Publication** - Page is published

- Deprecated servers

## Approval Model

Human approval applies to an exact content hash. Any content change after approval invalidates the approval.
