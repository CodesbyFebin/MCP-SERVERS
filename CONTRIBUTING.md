# Contributing

## Development Setup

```bash
git clone <repository-url>
cd MCP-SERVERS-master
npm install
cp .env.example .env.local
npm run dev
```

## Code Standards

- TypeScript strict mode
- ESLint configuration
- Prettier formatting
- Conventional commits

## Testing

```bash
npm run typecheck
npm run lint
npm run build
npm run seo:audit
```

## Content Contribution

1. Add sources to source registry
2. Extract evidence passages
3. Create entities with verified claims
4. Build relationships
5. Generate page contracts
6. Run quality gates
7. Submit for editorial review

## Pull Request Process

1. Create feature branch
2. Make changes
3. Run tests
4. Submit PR with description
5. Address review comments
6. Merge after approval
