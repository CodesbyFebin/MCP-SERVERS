# Operations

## Monitoring

Track:
- Pipeline runs
- Page candidates
- Publication rates
- Rejection reasons
- Evidence failures
- Duplicate rates
- Translation failures
- Broken links
- Sitemap errors
- Crawl activity
- Search usage
- Zero-result searches
- API latency
- Worker failures
- Security scan failures
- Stale claims
- Build duration
- Cost per published page

## Tools

- OpenTelemetry
- Structured logs
- Traces
- Metrics
- Sentry
- Alerting

## Backup

- Daily database backups
- S3 object versioning
- Point-in-time recovery

## Incident Response

1. Detect via monitoring
2. Assess impact
3. Mitigate
4. Communicate
5. Post-mortem
