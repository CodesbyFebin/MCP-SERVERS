# SEO, AEO, and GEO Requirements

## SEO Requirements

Every published page must include:
- Clear search intent
- One canonical URL
- One visible H1
- Logical H2/H3 hierarchy
- Direct answer near the top
- Definition where relevant
- Evidence-backed facts
- Entity relationships
- Original analysis
- Useful tables where supported
- Contextual internal links
- Breadcrumbs
- Structured data
- Author and review information
- Freshness information
- Source references
- Accessible media
- Descriptive image alt text
- Crawlable server-rendered content

## AEO Requirements

- Definition near the top
- Direct answer to query
- Structured data for entities
- FAQ schema when applicable
- HowTo schema for tutorials
- Clear entity identification
- Evidence-backed facts

## GEO Requirements

- Author credentials
- Review metadata
- Source citations
- Evidence date
- Editorial process transparency
- Quality scoring visible
- Correction mechanism

## Avoid

- Keyword stuffing
- Repetitive intros
- Generated filler
- Unsupported superiority claims
- Duplicate city/category variants
- Untranslated English fragments
- Thin programmatic pages
- Fake ratings
- Fake reviews
- Fake popularity scores
- Fake download numbers
