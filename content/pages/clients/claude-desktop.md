# Claude Desktop MCP Client

## Overview

Claude Desktop is a native MCP client that supports MCP servers.

## Setup

1. Download Claude Desktop
2. Configure MCP servers
3. Restart Claude Desktop

## Supported Features

- Tool execution
- Resource access
- Prompt integration

## Conclusion

Claude Desktop provides a seamless MCP experience.
