# The Complete Guide to MCP Server Marketplaces

## Introduction

Smithery.ai is the primary MCP server marketplace with 2,211+ servers. Glama.ai, MCP.so, PulseMCP, and Docker MCP Catalog are other key discovery platforms.

This comprehensive guide covers everything you need to know about mcp marketplace.

## Understanding The Complete Guide to MCP Server Marketplaces

A server listed on Glama is often also on MCP.so and PulseMCP. Smithery supports npm packages, GitHub repos, and Docker images.
