# MCP Clients: The Complete Guide

## Introduction

An MCP client is any application (like Claude Desktop, Cursor IDE, or custom CLI) that initiates a Model Context Protocol connection to a server to consume tools.

This comprehensive guide covers everything you need to know about mcp clients.

## Understanding MCP Clients: The Complete Guide

VS Code is a full MCP client supporting tools, resources, prompts, sampling, and OAuth. Clients parse server capabilities and render them to the underlying LLM.
