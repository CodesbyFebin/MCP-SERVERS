# MCP Architecture

## Overview

Model Context Protocol uses a client-host-server architecture.

## Components

### Host

The host application that initiates connections.

### Client

The client component that manages connections to servers.

### Server

The server that provides tools and resources.

## Conclusion

Understanding MCP architecture is essential for building MCP integrations.
