# MCP Host

## Definition

An MCP host is an application that initiates connections to MCP servers and exposes their capabilities to AI models.

## Role in MCP Architecture

The host acts as an intermediary between AI models and external tools/resources.

## Examples

- Claude Desktop
- Cursor
- Other MCP-compatible applications

## Conclusion

Understanding MCP hosts is essential for working with the Model Context Protocol.
