# MCP Tools Not Appearing

## Problem

MCP tools are not showing up in your MCP client.

## Common Causes

- Server not running
- Configuration errors
- Transport issues

## Solutions

1. Check server status
2. Verify configuration
3. Restart client

## Conclusion

Most MCP tool visibility issues are configuration-related.
