# MCP Server Not Connecting

## Problem

MCP server is not connecting to the client.

## Common Causes

- Server not running
- Network issues
- Authentication errors

## Solutions

1. Check server status
2. Verify network connectivity
3. Check credentials

## Conclusion

Most connection issues are configuration-related.
