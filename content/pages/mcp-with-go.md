# MCP with Go

## Introduction
Integrating MCP with Go enables high-performance AI applications.

## Integration
```go
package main

import (
  "github.com/modelcontextprotocol/go-sdk/server"
)

func main() {
  srv := server.NewServer(&server.ServerOptions{
    Name:    "my-server",
    Version: "1.0.0",
  })
}
```

Go provides excellent performance for MCP servers.
