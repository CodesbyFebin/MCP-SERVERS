# Bitbucket MCP Server Tutorial

## Introduction

This comprehensive tutorial teaches you how to use the Bitbucket MCP server effectively.

## About Bitbucket

Allows autonomous agents to perform file modifications, check commits, and manage pull requests on Bitbucket Cloud or Server.

## Key Features

- Repo checkout
- Pull request reviews
- Branch updates
- Commit search

## Use Cases

- Integrate codebases into LLM workflows
- Check branch status
- Review repository changes

## Setup

1. Install the MCP server
2. Configure authentication
3. Add to your MCP client
4. Test the connection

## Configuration

```json
{
  "mcpServers": {
    "bitbucket-mcp-server": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-bitbucket-mcp-server"],
      "env": {
        "API_KEY": "your-api-key"
      }
    }
  }
}
```

## Best Practices

- Use environment variables for credentials
- Monitor server logs
- Implement error handling
- Keep the server updated

## Conclusion

You now know how to use the Bitbucket MCP server. Start integrating it into your workflows!
