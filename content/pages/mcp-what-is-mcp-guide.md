# What is MCP? The Model Context Protocol Explained

## Introduction

MCP is an open protocol that standardizes how applications provide context to language models. APIs connect machines; MCP connects intelligence to machines.

This comprehensive guide covers everything you need to know about model context protocol.

## Understanding What is MCP? The Model Context Protocol Explained

MCP does not replace REST/gRPC — it is the layer that lets LLM agents discover and use tools. MCP client (AI agent) sends requests; MCP server exposes tools/data.
