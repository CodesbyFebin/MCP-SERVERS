# MCP with Kubernetes

## Introduction

Deploying MCP servers on Kubernetes enables high availability, scaling, and orchestration. This guide shows you how to use MCP with Kubernetes.

## Kubernetes Deployment

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: mcp-server
spec:
  replicas: 3
  selector:
    matchLabels:
      app: mcp-server
  template:
    metadata:
      labels:
        app: mcp-server
    spec:
      containers:
      - name: mcp-server
        image: mcp-server:latest
        ports:
        - containerPort: 3000
        env:
        - name: API_KEY
          valueFrom:
            secretKeyRef:
              name: mcp-secrets
              key: api-key
```

## Setup

1. Create Kubernetes manifests
2. Configure secrets and configmaps
3. Deploy to cluster
4. Test service connectivity

## Best Practices

- Use multiple replicas
- Configure health checks
- Set resource limits
- Use service mesh for communication

## Conclusion

Kubernetes enables scalable MCP server deployments. Use orchestration for production workloads.
