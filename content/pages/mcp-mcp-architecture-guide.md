# MCP Architecture: How AI Agents Connect to External Tools

## Introduction

MCP architecture is composed of a light protocol layer running over asynchronous I/O transport. It maintains a stateful connection for session duration.

This comprehensive guide covers everything you need to know about mcp architecture.
