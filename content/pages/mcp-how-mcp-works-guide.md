# How MCP Works: Core Architecture and Workflows

## Introduction

MCP works through a simple client-server handshake where the client launches the server and queries its capabilities via JSON-RPC 2.0.

This comprehensive guide covers everything you need to know about how mcp works.

## Understanding How MCP Works: Core Architecture and Workflows

Once initialized, the client can list resources, invoke tools, or fill prompt templates. The server responds with rich markdown, text, or binary content.
